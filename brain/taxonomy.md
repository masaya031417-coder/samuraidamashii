# 分類憲法（taxonomy）

このファイルは「第二の脳」に入るデータを、どのカテゴリに分けるかの**基準書**です。
AIはデータを分類する前に必ずこのファイルを読みます。だから分類がブレません。

判断に迷ったり、俺が分類を修正したときは、下の「判断ログ」に1行追記していきます。
**このファイルが育つほど、自動分類が賢くなります。**（モデルは変わらない。基準書が育つ）

---

## 分類ルール

1. **主カテゴリは必ず1つ**（＝そのデータの「家」）。下のカテゴリ一覧から選ぶ。
2. **タグは複数OK**（＝横串。後で「恋愛の全データ」「AIの全データ」を跨いで引くため）。
3. どのカテゴリにも合わないときは `未分類` にして、AIは「新カテゴリ提案」を添える。
4. AIが分類したら確信度 `confidence`（0.0〜1.0）を必ず付ける。
   - `0.8以上` … そのまま保存
   - `0.8未満` … 保存はするが「要確認」フラグを立て、俺に一言聞く
5. 俺が分類を直したら、その事例を「判断ログ」に追記する。

---

## カテゴリ一覧

### 経営
- **含む**: ビジネス戦略 / 組織・マネジメント / 採用 / リーダーシップ / お金の稼ぎ方 / マーケティング / 起業
- **含まない**: 個人の習慣・メンタル管理 → それは「自己啓発」

### AI
- **含む**: AI技術・モデル / AIツール / プロンプト / AI活用事例 / 自動化・エージェント
- **含まない**: 「AIで稼ぐビジネスモデル」の話が主なら「経営」（AIはタグに回す）

### 恋愛
- **含む**: 人間関係 / モテ・魅力 / コミュニケーション / 恋愛心理 / パートナーシップ
- **含まない**: 職場の人間関係マネジメント → 「経営」

### 自己啓発
- **含む**: 習慣化 / メンタル・マインドセット / 時間管理 / 目標設定 / 成長・学習法 / 健康・体づくり
- **含まない**: 具体的なビジネス手法 → 「経営」

---

## 迷ったときの優先順位

内容が複数にまたがるときは「**何のために書かれた文章か（主目的）**」で主カテゴリを決める。
残りはタグに回す。

例：「AI時代の恋愛マーケティング戦略」
→ 主目的は“稼ぐ手法” なので 主カテゴリ = **経営** / タグ = `AI, 恋愛, マーケ`

---

## 判断ログ（ここが育つ）

俺が分類を修正した事例・AIが迷った事例を、決まりとして残していく。

| 日付 | 内容 | AIの判断 | 正しい分類 | 学んだ基準 |
|---|---|---|---|---|
| （例）2026-08-05 | 「朝活で人生変わった話」 | 経営? | 自己啓発 | “習慣・生活”が主眼なら自己啓発 |
