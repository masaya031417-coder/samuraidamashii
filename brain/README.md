# 第二の脳（brain）

URLやYouTubeの内容を要約して、カテゴリ分けしてためていく個人ナレッジベース。
ためたデータを土台に、将来「英語アシスタント」や「各分野の先生（AIチーム）」を賢く育てていく。

## いま出来ること（フェーズ1：分類の土台）

- URL / YouTube字幕 / メモ を投げる → 要約 → **カテゴリ分類** → 保存
- カテゴリは主1つ + タグ複数（`taxonomy.md` が分類の基準書）

## フォルダ構成

```
brain/
├─ README.md      ← これ
├─ taxonomy.md    ← 分類の憲法（カテゴリ定義＋判断ログ／育つ）
├─ TEMPLATE.md    ← データ1件のフォーマット
└─ sources/       ← 要約データを全部フラットに置く（1件=1ファイル）
```

## 使い方（今の運用）

「URLを送る」＝**このリポジトリのClaude Codeセッションに URL か 字幕を貼る**だけ。
AIが以下をやる：

1. 中身を取得して要約
2. `taxonomy.md` を読んで分類（主カテゴリ＋タグ）
3. `sources/NNNN-タイトル.md` として保存
4. コミット

YouTubeで自動取得できないときは、字幕（「文字起こしを表示」からコピー）を一緒に貼る。

## 手動 → 自動 の育て方

| 段階 | やり方 |
|---|---|
| ① 手動 | 「これは経営」と俺が指定して送る |
| ② 半自動 | URLだけ送る → AIが分類を提案 → 俺がOK/修正 |
| ③ 自動 | 送るだけ。AIが自分で分類。自信ないときだけ聞く |

②③に進むほど、俺が直した事例が `taxonomy.md` の判断ログに溜まり、分類精度が上がる。

## この先の拡張（メモ）

- 8時／20時の定期実行（Routines）で、貯まったデータの復習・レッスン自動生成
- カテゴリごとの「先生」ペルソナ（経営の先生 / 英語の先生…）
- 貯めた要約に質問する（ノートに聞く／RAG）
